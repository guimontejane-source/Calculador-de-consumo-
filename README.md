Sistema de Cadastro de Colaboradores

Projeto desenvolvido para a atividade de Desenvolvimento de Sistemas II, com o objetivo de criar um sistema simples de cadastro de novos colaboradores.

O projeto utiliza HTML, CSS e PHP, com envio dos dados através do método POST. Após o preenchimento do formulário, as informações são processadas pelo PHP e apresentadas em uma página de confirmação, incluindo uma mensagem personalizada com os dados do candidato.

Tecnologias utilizadas

- HTML5
- CSS3
- PHP
- Método POST

Funcionalidades

- Cadastro de nome completo;
- Cadastro de idade;
- Cadastro de profissão;
- Cadastro de salário pretendido;
- Cadastro de experiência anterior;
- Processamento dos dados com PHP;
- Exibição dos dados cadastrados;
- Mensagem personalizada;
- Botão para retornar ao formulário.

Projeto desenvolvido com foco no aprendizado de programação server-side e integração entre HTML e PHP.
